## 个人中心

羽bot将更新token等操作整合到了 [个人中心](https://yubo.run/user/) 页面

群友登录后可以执行关联账号等相关操作

如果你在群里有群主或管理员权限，你可以在群列表中开启或关闭各项功能

### 登录

在群里发送 `@羽bot 个人中心` ，羽bot会发送如下的链接，把它复制到浏览器打开

<https://yubo.run/user/>

（每次发送的链接都是一样的，能打开就行，不用每次都发送指令）

（在这个页面也可以直接点击跳转不用再回去群里发.jpg）

填入QQ之后点击 `登录` ，在5分钟内用这个QQ在有羽bot的群里发送验证码即可登录。更新token、关联账号等操作的群内通知会发到本次登录的群；如需更换通知群，请退出后重新登录

也可以填入邮箱地址，点击 `登录` 后在网页中输入收到的邮件验证码。群聊设置、更新token、关联Steam和雀魂账号需要使用QQ登录

### 用户设置

在个人中心的 `用户设置` 中可以关联QQ、邮箱和哔哩哔哩账号，选择显示的昵称，修改称号的前缀和称号，也可以投稿新的前缀或称号。关联账号时按网页提示完成验证

## 明日方舟相关

包括集成战略统计和抽卡统计，使用本组件需要提供鹰角网络通行证登录凭证(token)以查询数据

羽bot会使用token定期从明日方舟官方接口更新游戏账号的集成战略和抽卡等数据，群友可以用指令查询相关统计。两类数据的自动更新间隔由羽bot配置决定，不保证在每小时整点更新；除了自动更新，也可以发送指令 `@羽bot 更新数据` 请求手动更新，稍后会在群里收到结果

### token

羽bot使用 [鹰角网络通行证](https://user.hypergryph.com/) 登录凭证(token)从官方接口查询数据，并关联通行证中的默认明日方舟角色

#### 更新token

在 [羽bot个人中心](https://yubo.run/user/) 登录后点击 `更新token` ，按照网页中的说明登录鹰角网络通行证、确认默认角色，再打开token页面，**全选**并复制页面内容

在输入框中填入刚才**全选**复制的token信息，提交后如果成功会在网页和群里收到结果

#### 移除token

别走好吗.jpg

在群里发送 `移除token` ，集器人会回复如下的消息

> 你确定吗？请在5分钟内发送“我确定要移除token”，若如此做，博士的token将被移除，与QQ的关联将被解除，其数据将不再被自动更新，但是已有的数据将被继续保留

在5分钟内发送 `我确定要移除token` 即可移除token

### 集器人

**集**成战略机**器人**，简称集器人

在群设置中开启 `明日方舟 - 集集雷达` 后，羽bot会在数据更新时检测探索记录和统计变化，并播报集集雷达消息。目前集集日报、集集周报没有开启定时播报

群友可以用指令查询相关统计

`查询萨米肉鸽统计` 的统计结果中，每个字有(触发坍缩范式次数-去除坍缩范式次数) * 0.05%的概率坍缩，😎戴上墨镜🕶可以防坍缩

目前可以查询古堡（傀影）、水月、萨米、萨卡兹、界园和树海肉鸽统计；萨米也可以用 `冰原`、`坍缩` 或 `木裂` 代替

`查询群友节点` 不指定主题时查询树海，可以在主题后指定 `随机`、`排序`、`降序`、`升序` 或 `难度`；默认降序排列。例如：`查询群友节点 界园 升序`

`查询群友存款` 不指定主题时查询萨卡兹，支持古堡（傀影）、水月、萨米和萨卡兹。两种查询都可以使用 `全部` 或 `累计` 查询各主题合计

#### 网页统计与公开设置

除了群内查询，还可以查看以下网页：

- [集集统计总榜（暂定）](https://yubo.run/arknights/ji/)
- [个人集集统计](https://yubo.run/arknights/ji/user.html)
- [全服集集统计](https://yubo.run/arknights/ji/server.html)

发送 `群友集集统计` 可以获取本群统计页面的链接，发送 `个人集集统计` 或 `我的集集统计` 可以获取个人统计页面的链接。群内和个人统计页面需要登录个人中心

在个人中心的明日方舟账号选项中，可以开启或关闭公开集集统计数据，并选择公开时是否匿名。也可以在群里发送 `公开集集统计 开启` 或 `公开集集统计 关闭` 修改公开状态；只发送 `公开集集统计` 会查询当前状态

### 森空岛

提交有效token后，可以在个人中心开启 `森空岛自动签到（测试中）`。该功能支持明日方舟和明日方舟：终末地签到

在群里发送 `状态` 可以查看关联角色的游戏状态，包括明日方舟的理智、基建和任务进度等；发送 `未拥有干员` 可以查看尚未拥有的明日方舟干员

### 公开招募

群主或管理员在个人中心的群设置中开启 `明日方舟 - 公招检测` 后，在群里发送一张公招截图，羽bot会尝试识别标签并计算能锁定四星、五星、六星或小车的组合

也可以发送 `公招计算 <标签1> <标签2> <标签3> <标签4> [标签5]` 手动计算。标签用空格分隔，至少需要四个有效标签。例如：`公招计算 高级资深干员 近战位 输出 防护 治疗`

### 抽卡统计

官网的抽卡记录只提供30天内最近100条（每次单抽算1条，每次十连算1条），如果（打算）在一小时内连续抽100条记录请及时手动更新数据以保证数据完整 ~~还没见过这么抽的群友~~

数据更新后，如果检测到抽卡记录更新，会自动请求 [明日方舟寻访记录分析](https://arkgacha.kwer.top/) 同步更新，即只要羽bot这边的token不失效，寻访记录分析那边的记录就不会因过期而失效

## Steam相关

羽bot可以自动播报群友的Steam游戏状态变化和Dota 2图文战报，也可以查询群友当前在玩的游戏和Dota 2天梯段位

### 关联Steam账号

在 [羽bot个人中心](https://yubo.run/user/) 登录后点击 `关联SteamID` ，填写SteamID（好友代码）并提交

### 开启播报

群主或管理员可以在个人中心的群设置中分别开启以下功能：

- `Steam - 游戏状态雷达 - Dota 2`
- `Steam - 游戏状态雷达 - 所有其他游戏`
- `Steam - 刀刀雷达`

游戏状态雷达会播报启动、切换和退出游戏等变化，刀刀雷达会播报Dota 2战报。游戏状态变化过于频繁时，羽bot会暂停该玩家在本群的状态播报，并提示预计恢复时间

### 查询指令

```
@羽bot 群友在干嘛
@羽bot 查询群友天梯段位
```

## 雀魂相关

羽bot会定时播报雀魂战报、雀魂周报

### 关联雀魂账号

在 [羽bot个人中心](https://yubo.run/user/) 登录后点击 `关联雀魂牌谱屋ID` ，前往 [雀魂牌谱屋](https://amae-koromo.sapk.ch/) 按名字找到自己的玩家页面，确认账号后将页面地址或玩家ID填入输入框并提交

群主或管理员可以在个人中心的群设置中开启 `雀魂 - 雀魂雷达` ，让羽bot播报本群已关联玩家的战报和周报

```
@羽bot 查询群友雀魂段位
```

## 其他功能/组件

### 你问我答

本节功能需要羽bot启用 `你问我答` 组件。可以设置仅自己触发的个人问答，或让全群成员触发的全群问答

| 指令 | 说明 |
| --- | --- |
| `@羽bot 我问早上好你答早安` | 添加个人问答，只有创建者发送“早上好”时会触发 |
| `@羽bot 有人问早上好你答早安` | 添加全群问答，需要群主或超级管理员权限；也支持“大家问” |
| `@羽bot 我的问答` | 查看自己的个人问答，也支持“看看我问” |
| `@羽bot 全体问答` | 查看本群全群问答，需要群管理员及以上权限 |
| `@羽bot 下一页` / `@羽bot 取消` | 继续或退出问答列表的分页 |
| `不要回答 id1` | 删除指定答案，也支持“删除回答”“删除问答” |
| `不要回答 早上好` | 删除该问题下自己有权管理的所有答案 |
| `QA帮助` / `问答帮助` | 查看帮助 |

设置问答、查看列表和翻页需要@羽bot；触发问题、删除问答和查看帮助不需要@。问题精确匹配，忽略首尾空白，支持文字、图片、表情和@，同一个问题可以有多个答案

问答按群隔离。个人问答只有创建者可删除；全群问答的设置和删除需要群主或超级管理员权限。分页超时后需要重新发送列表指令

### arkdle

基于 [nonebot-plugin-handle](https://github.com/noneplugin/nonebot-plugin-handle) 修改而成的 [改版handle](https://github.com/SonodaHanami/nonebot-plugin-handle) ，用到了[舟语词典](https://github.com/SonodaHanami/arknights_words/blob/master/answers_arknights.json)

#### 开始游戏

发送 `arkdle` 开始游戏

你有10次的机会猜一个四字舟语

每次猜测后，汉字与拼音的颜色将会标识其与正确答案的区别

<span style="color: #1d9c9c;">青色</span> 表示其出现在答案中且在正确的位置

<span style="color: #de7525;">橙色</span> 表示其出现在答案中但不在正确的位置，最大着色次数为这个声母/韵母在这个词语中出现的次数

下划线 表示这个声母韵母组合来自同一个字

每个格子的 汉字、声母、韵母、声调 都会独立进行颜色的指示

当四个格子都为青色时，你便赢得了游戏！

可发送 `结束` 结束游戏，发送 `提示` 查看提示

严格模式默认开启且无法关闭，即猜测的四字词语必须是舟语

使用 `--nohint` 选项禁用提示

使用 `--confirm` 选项开启确认模式，在猜测的四字词语不是舟语时会发送提示

使用 `--hard` 选项开启困难模式，可猜次数变为5，自动禁用提示，自动启用严格模式

例如：发送 `arkdle --nohint --confirm` 将开始一局禁用提示、开启确认模式的arkdle

#### 查询舟语

发送 `查询舟语 <四字舟语>` 可以查询四字舟语的拼音、所属范围、释义

### 其他群聊功能

#### 状态与称号

发送 `@羽bot 状态` 可以查看本群功能开关、明日方舟token和森空岛签到情况等；发送 `@羽bot 我是谁` 可以查看自己设置的昵称和称号，发送 `查询称号统计` 可以查看使用人数最多的称号组合

#### 掷骰与随机数

以下指令需要@羽bot：

| 指令 | 说明 |
| --- | --- |
| `@羽bot roll` | 随机生成1～100之间的整数 |
| `@羽bot roll 20` | 随机生成1～20之间的整数 |
| `@羽bot roll 10 30` | 随机生成10～30之间的整数，包含两端 |
| `@羽bot roll 2d6` | 掷两个六面骰，分别显示结果 |
| `@羽bot roll 2d6+1` | 掷两个六面骰，每个结果分别加1 |

骰子写法中的数量省略时默认为1，面数省略时默认为6；每组最多10个骰子，每个骰子最多1024面。也支持 `/roll`、`!roll`、`.roll`、`/r`、`!r` 和 `.r`

#### 加群/退群提醒

有新群友进群时羽bot会自动发送欢迎消息

有群友退群时羽bot会自动发送白白喵消息

#### 禁言我

在群里发送 `@羽bot 禁言我[<天数>天][<小时数>小时][<分钟数>分钟][<秒数>秒]` ，如果羽bot有合适的权限则会将你禁言

例如：发送 `@羽bot 禁言我3天33小时333分钟3333秒` 将获得时长4天15小时28分钟33秒的禁言

没有指定时长时，羽bot将随机决定一个1分钟到10分钟的禁言时长

指定的时长超过上限时，实际禁言时长最多为29天23小时59分钟59秒

你可以什么都不做，直到禁言自然结束

如果你已经登录个人中心，你可以在个人中心点击群号下方的 `请求解除禁言` 请求解除禁言

或者你可以使用紧急自救页面实现自救

<https://yubo.run/user/iambanned.html>
